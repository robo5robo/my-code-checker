# منصة فحص وتشغيل الأكواد - المعايير والخارطة

## الهدف
منصة مجانية تساعد الطلاب على فحص وتشغيل وتصحيح أكوادهم البرمجية،
بديل مجاني عن المنصات التجارية المدفوعة.

## قواعد ثابتة (لا تُخالف أبداً)
- لا تضع أي مفتاح API أو كلمة مرور أو سر داخل الكود مباشرة أبداً، استخدم متغيرات البيئة فقط.
- لا تشغّل كود الطالب (غير الموثوق) مباشرة على خادم المشروع أبداً، فقط داخل بيئة معزولة.
- اشرح كل تعديل جوهري قبل تنفيذه.
- المشروع مرتبط بـ GitHub وينشر تلقائياً عبر Render.

## خارطة الطريق والأدوات المقررة لكل مرحلة

المرحلة 0 - البنية الأساسية: Python + Flask + Docker + Git/GitHub
المرحلة 1 - الواجهة: Monaco Editor (أو CodeMirror 6 كبديل أخف)، Chart.js للوحة التقدم لاحقاً
المرحلة 2 - تشغيل الأكواد بأمان: Pyodide لتشغيل Python في متصفح الطالب،
            Piston (الواجهة العامة) للغات أخرى مؤقتاً، Judge0 لاحقاً على خادم كبير
المرحلة 3 - فحص الجودة: Ruff وPylint/Flake8 لـPython، ESLint لـJavaScript،
            Clang-Tidy وCppcheck لـC/C++، vnu لـHTML/CSS، jsonlint لـJSON
المرحلة 4 - التقييم والتعقيد: Lizard وRadon، معيار SQALE لحساب الديون التقنية
المرحلة 5 - الشرح بالذكاء الاصطناعي: Claude API أو Gemini API لشرح النتائج بالعربية
المرحلة 6 - الحسابات وGitHub (على خادم كبير): OAuth 2.0، Judge0+Isolate،
            PostgreSQL أو MongoDB
المرحلة 7 - الأمان المتقدم (خادم كبير): Semgrep، Gitleaks، Tree-sitter
المرحلة 8 - التوسع (خادم كبير): Celery، Redis/RabbitMQ، Docker+containerd

## ترتيب التنفيذ الحالي
نعمل الآن على المراحل 0 و1 و2 و3 و4 و5 فقط، على خادم Render المجاني.
المراحل 6 و7 و8 مؤجلة لحين الانتقال لخادم كبير، لا تبدأ بها الآن.
